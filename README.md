# 🌍 Global Airbnb Performance & Market Analytics Dashboard

An end-to-end Business Intelligence project built in Power BI to analyze global Airbnb data, uncovering user engagement patterns, market seasonality, and host reliability metrics.

---

## 📊 Project Overview
This project transforms raw multi-table Airbnb datasets into an interactive, stakeholder-ready dashboard. It is designed to track how listings grow, how travelers behave across different seasons, and how trust/verification metrics impact the platform.

### 🔑 Key Highlights & Insights
* **User Engagement:** Discovered that **98.8% of users review 3 times or less**, highlighting critical behavioral limits in user retention and review frequency.
* **Global Seasonality:** Uncovered geographic travel trends showing that **Paris and Rome** dominate review shares during peak European summer months (April–August), while hubs like **New York** surge during the winter holiday season.
* **Trust & Safety:** Evaluated host reliability, revealing that over two-thirds of hosts are fully verified with robust trust signals to keep unverified/anonymous profiles to a minimum.

---

## 🛠 Tech Stack & Methodology
* **Data Processing & ETL:** Handled multi-table data ingestion, resolved null values, and optimized data types using **Power Query**.
* **Data Modeling & DAX:** Developed complex measures including cumulative percentage calculations and aggregations to drive dynamic visuals.
* **Dashboard Design:** Designed following professional UI/UX standards with custom color themes, clean visual hierarchy, and intuitive user navigation.
